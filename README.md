# SinStarI

**Created by: Louiery R. Sincioco (Sin)**

Sin Star I is a game in development and the first game project to use the new
SMILE Programming Language, Compiler, Libraries and Tool Chain.

This repository currently contains the illustrated script and visual storyboard.
The game project may join it later. The compiler and tool chain remain at
[Sincioco/SMILE-2.0](https://github.com/sincioco/smile-2.0).

## Open the story

See [Visual Script and Storyboard/Start Here.md](Visual%20Script%20and%20Storyboard/Start%20Here.md).
The HTML, illustrations and production materials are kept together in that folder.

Video files are deliberately excluded from Git. Local videos play when present;
verified YouTube versions provide online playback for shared copies.

Future edits are made directly in this working folder. ZIP exports are optional
and produced only on request.
